# 关于

这里是「每天和 AI 的精彩内容」：把当天跟 AI 协作里值得留下来的片段整理成文，一天一篇，能抄走的做法优先。

## 这个站点是什么

- 每天一条：提示词、工作流、工具、踩坑、思考，五类标签；
- 完全独立的静态站点，与旧的 VuePress 仓库没有代码或配置上的耦合；
- 使用本地搜索，不依赖任何第三方搜索服务。

## 写作约定

| 字段 | 说明 |
| --- | --- |
| `title` | 一句话说清当天最值得记的点 |
| `date` | `YYYY-MM-DD`，决定归档顺序 |
| `tags` | 提示词 / 工作流 / 工具 / 踩坑 / 思考 |
| `summary` | 60 字以内，显示在归档页 |
| `aiModel` | 可选，涉及的模型或工具 |
